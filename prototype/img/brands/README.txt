Put the official brand logo files here as SVG (PNG works too if you change the extension in brands4.js).
Use the files from each brand's own press or media page. Do not redraw or generate logos.

File names the site expects:
apple.svg        (Apple, iPad, MacBook)
samsung.svg      (Samsung, Galaxy Tab)
google.svg       (Google Pixel)
xiaomi.svg
huawei.svg       (Huawei, Huawei MateBook)
oneplus.svg
oppo.svg
sony.svg         (Sony Xperia)
motorola.svg
lenovo.svg
hp.svg
dell.svg
asus.svg
acer.svg
microsoft.svg    (Microsoft Surface)
msi.svg
playstation.svg  (PlayStation, DualSense)
xbox.svg
nintendo.svg     (Nintendo Switch, Joy-Con)
steam.svg        (Steam Deck)

After adding a file, add its name (without .svg) to BRAND_LOGOS_READY in prototype/src/brands4.js and rebuild,
or upload it to the brand in the Django admin on the live site.
